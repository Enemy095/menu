# API-001 — OpenAPI-first public contract

Status: `superseded`
Wave: 1  
Dependencies: `PLAN-001`, `LEG-001`

## Objective

Создать единственный source of truth для public restaurant, menu и order API, а также детерминированную генерацию `typescript-fetch` client. Контракт не должен раскрывать внутренний `tenantId`, notification destinations или secrets.

## Exclusive ownership

Агент единолично владеет `packages/api-contract/**`.

Не изменять root pnpm/Gradle wiring, `apps/**`, `infra/**`, migration docs и legacy. Package должен иметь собственные scripts/config и быть готовым к последующему подключению в pnpm workspace.

## Fixed endpoints

```text
GET  /api/v1/public/{tenantSlug}/restaurant
GET  /api/v1/public/{tenantSlug}/menu
POST /api/v1/public/{tenantSlug}/orders
```

Tenant определяется trusted host + path slug. `tenantId`, `businessSlug` и `idempotencyKey` не находятся в order body. Idempotency key передаётся только через header.

## Contract requirements

### Restaurant

Включает public restaurant ID/slug, branding, SEO texts, hero/design tokens/localized texts, public profile, features, order types, limits, locale, currency и timezone. Исключает manager phone, destination config, storage keys и secrets.

### Menu

Включает restaurant ID, version, publishedAt, currency, ordered categories и items. Item содержит stable public ID, category ID, name, description, `priceMinor`, image URL, availability и sort order.

### Create order

Request:

```text
orderType: preorder | delivery | pickup
customer: name, phone, optional address
items: menuItemId + quantity
optional comment
optional guestCount (1..99)
clientTotalMinor
clientCreatedAt
clientMenuVersion
```

Response:

```text
orderId
orderNumber
status=new
serverTotalMinor
currency
serverReceivedAt
needsConfirmation
```

### Errors

Единый envelope:

```json
{
  "code": "VALIDATION_ERROR",
  "message": "Некорректные данные заказа",
  "details": [{ "field": "customer.phone", "reason": "INVALID_FORMAT" }],
  "traceId": "..."
}
```

Зафиксировать codes минимум для `TENANT_NOT_FOUND`, `VALIDATION_ERROR`, `MENU_CHANGED`, `ITEM_UNAVAILABLE`, `TOTAL_MISMATCH`, `IDEMPOTENCY_CONFLICT`, `RATE_LIMITED`, `INTERNAL_ERROR`.

## Deliverables

- OpenAPI 3.0.3 split либо single spec с предсказуемой структурой.
- Examples Stambul и Adamas для restaurant/menu.
- Examples всех order types и error codes.
- Redocly lint configuration.
- OpenAPI Generator 7.22.x configuration для `typescript-fetch`.
- Generated client output в определённом каталоге и `package.json` exports.
- Scripts `lint`, `generate`, `check-generated` и contract validation tests.
- Generation должна быть deterministic; timestamps/banner noise отключены.
- README с local commands и правилом «generated files не редактировать».
- ADR/decision note внутри package: TypeScript client generated, Java controllers implemented manually against contract.

## Non-goals

- Java server stubs.
- Backend controllers.
- Root pnpm workspace.
- Admin API.
- Payment, loyalty или reservation API.

## Acceptance

- Spec lint проходит без warning, подавленных без объяснения.
- Generation дважды подряд не меняет working tree.
- Generated TypeScript компилируется package-local командой.
- Public schemas не содержат `tenantId`, `managerPhone`, raw destination/secret или object storage key.
- New order body не содержит `businessSlug` и `idempotencyKey`.
- Все endpoints имеют success/error examples и operation IDs.
- `git diff --check` проходит.
