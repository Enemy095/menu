# AST-001 — tenant asset storage and CDN policy

Status: `done`
Wave: 3  
Dependencies: `DB-001`, `TEN-001`, `INF-001`

## Objective

Создать S3-compatible adapter для import-time tenant assets и единый immutable CDN URL policy. Admin upload API не входит в задачу.

## Ownership

Asset port/adapters/config/tests в backend, MinIO integration fixtures и asset-specific persistence. Не менять branding/menu controllers или Compose ownership без coordination.

## Fixed key format

```text
tenants/{tenantId}/{assetKind}/{sha256}.{ext}
```

## Deliverables

- Storage port independent from AWS SDK.
- S3 adapter и local MinIO configuration.
- Content type, extension, size и checksum allowlists.
- Idempotent import by tenant + kind + hash.
- CDN/base URL resolver, никогда не публикующий credentials/raw secret.
- Tenant ownership checks before lookup/import.
- Immutable cache headers and content-hash semantics.

## Tests and acceptance

- MinIO Testcontainers/Compose integration upload и resolved URL.
- Same content idempotent within tenant.
- Tenant A не адресует key/record tenant B.
- Invalid type/size/hash rejected.
- Public URL deterministic, immutable и без credentials.
- Gradle check и `git diff --check` проходят.

## Non-goals

Browser direct upload, image transformation, admin UI, CDN vendor-specific purge API.
