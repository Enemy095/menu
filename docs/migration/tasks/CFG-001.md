# CFG-001 — public restaurant configuration API

Status: `ready`
Wave: 4  
Dependencies: `API-001`, `TEN-001`, `DB-001`, `MOD-001`

## Objective

Реализовать `GET /api/v1/public/{tenantSlug}/restaurant` как tenant-scoped typed read model без утечки private destinations/secrets.

## Deliverables

- Query use case и bounded JPA projection/query repository.
- OpenAPI-compatible controller/mapper.
- Public restaurant, branding, SEO, hero/design tokens/localized texts, profile, features, order types, limits, locale/currency/timezone.
- Asset URLs через AST port; raw object keys не возвращаются.
- ETag на config revision.
- Baseline cache policy: browser 60s, shared 300s, stale-while-revalidate 60s.
- Tenant-scoped cache/surrogate tag; no Redis dependency.

## Tests

- Stambul/Adamas contract fixtures.
- Unknown/inactive tenant 404.
- Host/path mismatch 404.
- Manager phone, destination config, `tenantId`, secrets и storage keys отсутствуют.
- Feature/order type combinations round-trip correctly.
- Fixed query count, no N+1.

## Acceptance

Response validates against generated OpenAPI examples, tenant isolation suite and Gradle check pass, cache headers/ETag deterministic.
