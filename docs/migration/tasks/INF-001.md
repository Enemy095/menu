# INF-001 — local infrastructure baseline

Status: `done`
Wave: 1  
Dependencies: `PLAN-001`

## Objective

Создать безопасную и воспроизводимую local infrastructure для PostgreSQL, optional tenant assets и optional observability без преждевременного Redis/broker.

## Exclusive ownership

Агент единолично владеет:

- `infra/**`;
- root `compose.yaml` или `docker-compose.yml`;
- root `.env.example`, если его нет.

Не изменять `apps/**`, `packages/**`, Gradle/pnpm files, migration docs, `AGENTS.md` и legacy.

## Fixed decisions

- PostgreSQL 17 — default service.
- MinIO доступен только через Compose profile `assets`.
- OpenTelemetry Collector и Prometheus доступны только через profile `observability`.
- Redis, Kafka/RabbitMQ и production credentials отсутствуют.
- Все defaults предназначены только для local development и явно помечены.
- Named volumes не удаляются обычным `down`; destructive reset — отдельная документированная команда.

## Deliverables

- Compose services с healthchecks:
  - `postgres`;
  - `minio`/bucket initializer under `assets` profile;
  - `otel-collector` и `prometheus` under `observability` profile.
- Стабильные local ports без конфликта с legacy frontend 8000 и планируемым API 8080.
- Named networks и volumes.
- `.env.example` с non-secret local values и placeholders для production-only variables.
- OTel Collector config, не отправляющий telemetry во внешний сервис по умолчанию.
- Prometheus config для будущего Actuator endpoint.
- `infra/local/README.md` с start, health, logs, stop и destructive reset commands.
- PowerShell-friendly команды и platform-neutral Compose syntax.
- `.gitignore` adjustments только если нужны для local generated data; tracked configs не должны содержать runtime state.

## Required checks

- `docker compose config` успешно валидирует default configuration.
- `docker compose --profile assets config` и `--profile observability config` успешны.
- `docker compose up -d postgres` доводит service до healthy.
- PostgreSQL принимает connection с documented local values.
- Stop/start сохраняет named volume data.
- Destructive reset описан с явным предупреждением.

## Non-goals

- Production Terraform/Kubernetes.
- Backend migrations или fixtures.
- Redis/broker.
- External Sentry/OTel credentials.
- CI deployment.

## Acceptance

- Default `docker compose up postgres` не запускает optional services.
- Все images имеют explicit non-floating major/minor tags.
- Нет production secrets или real tenant data.
- Healthchecks не зависят от host-installed tools.
- README соответствует реально выполненным командам.
- `git diff --check` проходит.
