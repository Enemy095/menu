# OBS-001/CI-001 — observability and quality gates

Status: `done`
Wave: 2, extended through all waves  
Dependencies: `BE-001`, `API-001`, `INF-001`

## Objective

Создать production-safe telemetry baseline и CI, которые расширяются вместе с domain modules и блокируют contract, tenancy, migration и generated-code drift.

## Observability deliverables

- Structured JSON production logs.
- Correlation/trace ID in error envelope, logs and worker spans.
- OTel OTLP configuration; local collector profile.
- Actuator liveness/readiness with DB-aware readiness.
- HTTP/JVM/DB-pool baseline metrics.
- Later hooks: tenant resolution failures, order outcomes, idempotency, outbox backlog/delivery.
- No phone/address/comment/user/order ID/raw unbounded host in metric labels.
- Tenant slug/ID only in logs/traces with explicit retention; evaluate metric cardinality before tenant label.
- PII redaction tests.

## CI pipeline

```text
OpenAPI lint/compatibility
→ generated TS diff check/typecheck
→ frontend lint/typecheck/unit/build
→ backend compile/unit/Modulith verify
→ PostgreSQL Testcontainers/Flyway validation
→ contract/isolation/idempotency/outbox tests as available
→ Playwright E2E
→ dependency/secret/container scans
→ bootJar/container/SBOM artifacts
```

## Rules and acceptance

- Java 25 and checked-in Gradle Wrapper.
- pnpm lockfile frozen.
- No shared long-lived CI database.
- Tests parallel-safe.
- Generated drift, Flyway validation, tenant isolation, idempotency and production build failures block merge.
- Liveness remains up while DB outage makes readiness down.
- Error response trace ID matches log trace.
- CI secrets never available to untrusted preview code.
