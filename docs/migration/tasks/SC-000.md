# SC-000 — single-client architecture reset

Status: `done`
Wave: P0
Dependencies: none

## Objective

Зафиксировать ADR-0003 и заменить multi-tenant target на один клиент на deployment до
начала новых code mutations.

## Deliverables

- root `AGENTS.md` с single-client rules;
- ADR-0003 и superseded status прежних tenant ADR;
- database/backend, API/security и frontend/delivery impact audits;
- single-client implementation plan;
- task registry со всеми SC tasks;
- historical notices на two-tenant import/security docs;
- удаление незакоммиченных MIG-001B parser/dry-run/CLI artifacts.

## Acceptance

- active target documents не требуют tenant abstraction;
- old tenant tasks помечены `superseded`;
- выбран append-only schema path, пока отсутствие deployed V1–V5 databases не доказано;
- конкретный Stambul/Adamas dataset остаётся явным product gate;
- Markdown links и `git diff --check` корректны;
- architecture checkpoint commit создан до P1.

## Non-goals

- Не менять Java/SQL/OpenAPI runtime в этом task.
- Не выбирать production dataset без подтверждения владельца.
- Не удалять V1–V5.
