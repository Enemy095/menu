# WEB-001 — Next.js tenant-aware SSR shell

Status: `planned`  
Wave: 5  
Dependencies: `API-001`; real-data acceptance also requires `CFG-001`, `MENU-001`

## Objective

Создать `apps/web` и root pnpm workspace с Next.js App Router, strict TypeScript и server-first tenant routing. На этом этапе shell отображает typed fixture/contract data и готов к generated client; полноценный menu UI относится к WEB-002.

## Ownership

- Root pnpm workspace files, если ещё не созданы.
- `apps/web/**`.
- Не изменять backend, OpenAPI generated sources, infra или legacy.

## Fixed decisions

- Route `/[tenantSlug]` для platform path.
- Custom-domain resolution выполняется server-side; browser не передаёт trusted tenantId.
- Server Components default; Client Components only when needed.
- Unknown tenant → `notFound()`, production fallback запрещён.
- Generated API client wrapped in server-only adapter.
- No registry containing every tenant in client bundle.

## Deliverables

- pnpm workspace и locked dependencies.
- Next.js app with strict `tsconfig`, ESLint, Prettier, Vitest/Testing Library и Playwright setup.
- Route layout/page, `loading`, `error`, `not-found`.
- Server-side effective host normalization and resolution request adapter aligned with API precedence.
- Typed server data gateway with timeouts, safe errors and correlation header forwarding.
- Dynamic metadata: title, description, canonical, Open Graph, favicon placeholders.
- Tenant design-token provider using validated CSS variables.
- Security headers baseline and `server-only` boundaries.
- Fixture mode is test/dev only and cannot silently activate in production.

## Tests

- Platform path and custom host resolve expected fixture tenant.
- Host/path mismatch and unknown tenant produce 404.
- SSR HTML and RSC payload for A contain no B data.
- Metadata/canonical are tenant-specific.
- No secret/internal tenantId exposed to browser.
- Client bundle does not contain full tenant registry.
- Loading/error/not-found accessible.

## Acceptance

`pnpm --filter web lint`, `typecheck`, `test` и production build проходят. Playwright smoke covers both tenants and unknown host/path. `git diff --check` passes.
