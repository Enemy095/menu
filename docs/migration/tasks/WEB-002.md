# WEB-002 — white-label menu browsing UI

Status: `superseded`
Wave: 5  
Dependencies: `WEB-001`, `CFG-001`, `MENU-001`

## Objective

Перенести branding, contacts, menu browsing и Adamas delivery presentation в declarative React components без tenant slug branches и direct DOM mutations.

## Deliverables

- Header/logo/brand copy.
- Hero, cuisine, slogan, intro и schedule.
- Contacts, phone, safe map/social links.
- Category navigation, «Все», visible item count.
- Dish grid/cards, validated image component/fallback, minor-unit money formatting.
- Config-driven widgets: popular items, category cards, delivery benefits/CTA.
- Shared theme tokens; Stambul/Adamas visuals expressed only by tenant data.
- Responsive mobile/desktop layout shell for future cart.
- Safe URL/image policy aligned with CDN/CSP.
- Keyboard navigation, visible focus, reduced motion и semantic controls.

## State rules

- Restaurant/menu remain server/query data, not Zustand.
- Only category selection and ephemeral UI state are client-local.
- No `querySelector`, synthetic click, `innerHTML` or globally mutable registry.
- Item/card components do not perform hidden API requests.

## Tests and acceptance

- Stambul renders 23, Adamas 19 items in exact order.
- Category ordering, filter and count match legacy.
- Prices are formatted from minor units/currency.
- Adamas widgets render from config; Stambul does not receive them.
- All CTA/category controls work by mouse and keyboard.
- Broken/unsafe image receives controlled fallback.
- Visual regression at agreed mobile/desktop viewports.
- Accessibility scan has no serious/critical violations.
- No hardcoded tenant slug branches.
- Frontend lint/typecheck/unit/build/E2E pass.
